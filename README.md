# 🚀 HaYTooL Cloud StartPage

> Modern, ultra hızlı, estetik, modüler ve gizlilik odaklı yeni sekme (New Tab / StartPage) tarayıcı eklentisi.

---

## ✨ Özellikler

- ⚡ **Ultra Hızlı Açılış:** Sıfır gecikme (zero-latency) ile anında açılan yeni sekme deneyimi.
- 🎨 **Modern & Premium Tasarım:** Glassmorphism, dinamik tema motoru (Koyu/Açık Tema), akıcı mikro animasyonlar.
- 🧩 **Modüler Widget Sistemi:**
  - Akıllı Arama Çubuğu (Google, DuckDuckGo, Bing, YouTube, GitHub vb. hızlı geçiş)
  - Hızlı Erişim & Favori Kısayollar (Özelleştirilebilir ve kategorize edilebilir)
  - Dijital / Analog Saat & Tarih ve Karşılama Mesajı
  - Hızlı Not Defteri & To-Do Listesi
  - Hava Durumu Göstergesi
  - Sistem / Ağ Durumu ve Kısayollar
- 🔒 **Gizlilik Odaklı (Privacy First):** Verileriniz tamamen yerel (local storage) üzerinde saklanır, harici sunuculara veri aktarımı yapılmaz.
- 🌍 **Çoklu Dil Desteği (i18n):** Türkçe, İngilizce ve diğer diller.
- 🛠️ **Manifest V3:** Güncel Chrome ve Chromium standartlarına tam uyumlu mimari.

## 📦 Kurulum ve Geliştirici Modunda Çalıştırma

1. Chromium tabanlı tarayıcınızı açın (Chrome, Brave, Edge, Opera).
2. Adres çubuğuna chrome://extensions (veya dge://extensions, rave://extensions) yazıp Enter'a basın.
3. Sağ üstteki **Geliştirici Modu**'nu (Developer mode) aktif edin.
4. **Paketlenmemiş öge yükle** (Load unpacked) butonuna tıklayın ve HaYTooL Cloud StartPage klasörünü seçin.
5. Yeni bir sekme açarak **HaYTooL Cloud StartPage** deneyimini test edin!
