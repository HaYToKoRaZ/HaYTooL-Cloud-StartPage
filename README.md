# 🚀 HaYTooL StartPage

> Modern, ultra hızlı, estetik ve modüler yeni sekme (New Tab / StartPage) tarayıcı eklentisi.

---

## ✨ Özellikler

- ⚡ **Ultra Hızlı Açılış:** Sıfır gecikme (zero-latency) ile anında açılan yeni sekme deneyimi.
- 🎨 **Modern & Premium Tasarım:** Glassmorphism, dinamik arka planlar, koyu/açık tema desteği ve akıcı mikro animasyonlar.
- 🧩 **Modüler Widget Sistemi:**
  - Akıllı Arama Çubuğu (Google, DuckDuckGo, Bing, YouTube, GitHub vb. hızlı geçiş)
  - Hızlı Erişim & Favori Kısayollar (Özelleştirilebilir ve kategorize edilebilir)
  - Dijital / Analog Saat & Tarih
  - Hızlı Not Defteri & To-Do Listesi
  - Hava Durumu Göstergesi
  - Sistem / Ağ Durumu ve Kısayollar
- 🔒 **Gizlilik Odaklı (Privacy First):** Verileriniz tamamen yerel (local storage) üzerinde saklanır, harici sunuculara veri aktarımı yapılmaz.
- 🛠️ **Manifest V3:** Güncel Chrome ve Chromium standartlarına tam uyumlu mimari.

## 📦 Kurulum ve Geliştirici Modunda Çalıştırma

1. Projeyi klonlayın veya indirin:
   ```bash
   git clone <repo-url>
   ```
2. Chromium tabanlı tarayıcınızı açın (Chrome, Brave, Edge, Opera).
3. Adres çubuğuna `chrome://extensions` (veya `edge://extensions`, `brave://extensions`) yazıp Enter'a basın.
4. Sağ üstteki **Geliştirici Modu**'nu (Developer mode) aktif edin.
5. **Paketlenmemiş öge yükle** (Load unpacked) butonuna tıklayın ve `haytool-startpage` klasörünü seçin.
6. Yeni bir sekme açarak **HaYTooL StartPage** deneyimini test edin!
